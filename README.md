## 1. Optimal intervention strategies project
A Python to compare several decision making frameworks for identifying **cost-effective dengue intervention strategies**.
The framework supports simulation and optimization of public health responses, enabling decision-makers to determine **when**, **where**, and **how intensively** interventions should be deployed to maximize disease prevention under resource constraints.
