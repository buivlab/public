# Optimal Intervention Strategy Framework
The framework supports simulation and optimization of public health responses, enabling decision-makers to determine **when**, **where**, and **how intensively** interventions should be deployed to maximize disease prevention while minimizing resource use.

---

## Overview

Dengue control programs often face limited resources and must decide:

- Which locations should receive interventions?
- When should interventions be triggered?
- Which intervention type should be selected?
- How should limited budgets be allocated across multiple regions?

This project provides a reproducible framework to evaluate and optimize intervention decisions using forecasted dengue risk and intervention effectiveness.

---

## Features

### Forecast-Based Decision Support

- Uses multi-step dengue forecasts to guide decision
- Incorporates uncertainty estimates

### Intervention Optimization

- Budget-constrained optimization
- Resource allocation across locations
- Cost-effectiveness analysis
- Compare Model Predictive Control, Greedy strategies

### Intervention Simulation

- Source reduction

### Epidemiological Impact Assessment

- Cases averted
- Reduction in incidence
